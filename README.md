# 同樂國小 校園導覽（訪客版）

宜蘭縣員山鄉同樂國小的 3D 校園導覽。單一 HTML 檔，使用 Three.js r128（由 cdnjs 載入），電腦與手機皆可使用。

## 直接使用
- 啟用 GitHub Pages（Settings → Pages → Branch: main / root），網址根目錄即開啟 `index.html`。
- 需要網路載入 Three.js 與字型。

## 功能
- 只有鳥瞰：拖曳旋轉、滾輪或雙指縮放、WASD 平移。
- 兩個導覽起點：校門口、後門。
- 四個參觀地點：行政辦公室、校史室、禮堂、草原班；點選後鏡頭飛過去並切到該樓層露出室內。
- 選好起點與地點後，顯示建議路線（沿建築通廊）與流動箭頭，並提示距離、步行時間與是否需上樓。
- 中文／English 切換：右上角「中文｜EN」；選擇會記在瀏覽器。英文版校名顯示為 TLPS，校徽不變。
- 不含：主題、人物、日夜、風格切換、VR、搜尋。

## 修改內容
- 簡介文字與起點座標：`part9.js` 最上方的 `VISIT_STARTS`、`VISIT_PLACES`。
- 增減參觀地點：在 `VISIT_PLACES` 加入地點名稱（須與校園房名一致，例如「圖書館」）。

## 中英翻譯
- 英文字典在 `part2.js` 最上方的 `EN`（含房名、設施、介面文字）；班級「N忠」等規則在 `tr()`。
- 地點介紹的英文在 `EN` 內以中文原句為鍵；新增參觀地點時，記得在 `EN` 補上名稱與介紹。

## 重新建置
執行 `bash build.sh`（需要 node）：合併 `part*.js` 成 `school.html` 並複製為 `index.html`。`index.html` 需一併提交到 GitHub。

## 檔案結構
- `part1.html`：頁面骨架與樣式
- `part2.js`、`part2d.js`、`part2e.js`：場景、材質、後處理
- `part3a/3b/3c.js`：建築與校園場景
- `part4.js`：鳥瞰相機與操作；`part5.js`：路徑搜尋與路線箭頭；`part6.js`、`part7.js`：既有引擎模組（訪客版已停用 VR 與角色）
- `part9.js`：訪客版介面、起點與地點、路線呈現
